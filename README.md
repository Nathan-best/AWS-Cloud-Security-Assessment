# AWS Cloud Security Assessment

## Project Overview

This project demonstrates the assessment, implementation, and monitoring of security controls within an AWS cloud environment.

The project focuses on identity security, least privilege, MFA, logging, encryption, threat detection, configuration compliance, and security monitoring.

## AWS Services

* AWS IAM
* IAM Policies
* MFA
* AWS CloudTrail
* Amazon S3
* AWS KMS
* Amazon GuardDuty
* AWS Security Hub
* AWS Config
* Amazon CloudWatch

## Project Objectives

* Assess IAM permissions and least-privilege controls
* Implement and evaluate MFA
* Configure centralized CloudTrail logging
* Secure S3 resources
* Implement encryption using AWS KMS
* Enable threat detection with GuardDuty
* Centralize security findings with Security Hub
* Evaluate AWS resource configurations with AWS Config
* Implement security monitoring with CloudWatch

## Security Assessment Process

The project follows:

**Identify → Assess → Remediate → Validate → Monitor**
